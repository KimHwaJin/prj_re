# 외부 리뷰 기록

이 디렉토리는 개발 작업과 분리된 **외부 리뷰 결과와 개선 검토 요청**을 보관한다.
작업 기록인 [improvements](../improvements/README.md)와 달리, 여기의 항목은 아직 채택되지 않은 제안이다.
개발 작업자가 검토하고 의견을 남긴다.

## 진행 방식

1. 리뷰마다 `YYYY-MM-DD-<주제>.md` 파일을 하나 추가하고, 아래 목록에 기준 commit과 함께 등록한다.
2. 각 항목에는 `R-xx` 같은 ID와 우선순위를 붙인다.
   - **P0**: 운영 장애 위험
   - **P1**: 설계 구조
   - **P2**: 정리·위생
3. 개발 작업자는 각 문서 상단의 **검토 응답표**에서 `상태`와 `의견`을 갱신한다.
   - 상태: `미검토` / `수용` / `부분 수용` / `보류` / `반려`
   - 반려나 보류일 때는 사유를 한 줄 남긴다.
4. 수용한 항목을 구현할 때는 기존 절차대로 `improvements/NNN-*.md`에 작업 기록을 남기고, 응답표의 의견란에 그 번호를 적는다.
5. 리뷰 문서의 본문(근거·제안)은 작성 시점의 기록으로 남긴다. 사실관계 정정은 응답표나 하단 정정란에 적는다.

## 근거 표기

- **확인**: 코드를 직접 읽었거나 실행해서 확인한 내용
- **추론**: 코드 구조로부터 판단했지만 실행으로 재현하지 않은 내용
